# Changelog

## 1.0.25

- Исправлен no-TOC сценарий, в котором два или несколько unresolved turn-slot могли одновременно быть причиной разрыва canonical chain и блокировать собственный `TARGETED_REPAIR`.
- Добавлен безопасный eligibility-path `structural-no-toc` для локальной классификации небольшого числа unresolved slot.
- Финальный критерий `COMPLETE` не ослаблен: после repair выполняется обычная повторная строгая проверка связности.
- Сохранено исправление 1.0.24 для проверки сериализации noncanonical turn-slot по фактически вставленным serializer-ом идентификаторам.

## 1.0.24

- Устранен ложный `INCOMPLETE`, возникавший, когда внутри текста самого чата встречались буквальные примеры `<!-- noncanonical-turn: ... -->`.
- Проверка сериализации переведена с повторного regex-парсинга всего Markdown на точный набор turn-id, реально вставленных serializer-ом.

## 1.0.23

- Более консервативная привязка date/time separator к сообщениям.
- Расширена диагностика неизвестных noncanonical turn-slot.
- Checkpoint payload обновлен до schema 16 с безопасной миграцией предыдущего состояния.

## 1.0.22

- Добавлена возможность доказать полноту длинного чата без TOC при строгом структурном подтверждении canonical chain и turn-skeleton.
