# Инструкции по репозиторию

- Не изменяй публичные интерфейсы без явной необходимости.
- Не выполняй рефакторинг кода, который не относится к задаче.
- Не записывай токены, ключи доступа и содержимое пользовательских чатов в журналы.

## Code Review Rules

- Отмечай изменения, способные нарушить обратную совместимость.
- Отмечай возможную потерю или повреждение данных.
- Отмечай утечки конфиденциальной информации.
