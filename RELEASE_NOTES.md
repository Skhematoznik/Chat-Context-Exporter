# Chat Context Exporter 1.2 — Release Notes

**Версия:** 1.2  
**Тип:** стабильный выпуск  
**База:** проверенный кандидат 1.2.4 (функции и патчи 1.1–1.2.4)  
**Распространение:** бесплатно, исключительно через GitHub Releases; ручная установка в Chrome/Chromium.

## Что нового относительно 1.0

- **ChatGPT DIL/MDX → Markdown:** переносимые ссылки, видимые статусы, простые таблицы, очистка декоративных компонентов. Исходные примеры кода не преобразуются. Неподдерживаемые динамические фрагменты сохраняются без выполнения JS.
- **Более надёжная загрузка длинных чатов:** строгая последовательность курсоров, буфер каскадных страниц, диагностика отсутствующего звена без сохранения неполной истории.
- **Восстановление после HTTP 403:** один повтор текущего прохода после 2,5 секунд и обычной перезагрузки. Отказ при повторной 403 не скрывается.
- **Ожидание завершения ответа ChatGPT:** проверка кнопки Stop перед первым сбором, после reload и перед скроллингом; пользовательский лимит ожидания по умолчанию 300 секунд, диапазон 30–3600 секунд.
- **Безопасный результат дополнительного прохода:** при невозможности необязательной проверки сохраняется только уже полностью собранный основной проход с явным предупреждением.
- **Исправления Markdown:** таблицы вида `|---|---|` → `| --- | --- |` и сохранение пробелов в DOM-заголовках последнего сообщения.

## Проверки и ограничения

- 49/49 автоматизированных тестов. Проверка синтаксиса всех 24 JavaScript-файлов расширения.
- Реальный экспорт длинного чата: 2 прохода по 15 страниц, 148 сообщений, 178 распознаваемых таблиц, 49 корректно закрытых блоков кода, `COMPLETED`.
- Восстановление после `HTTP 403` подтверждено отдельным браузерным запуском предшествующего кандидата 1.2.3; код восстановления в 1.2.4 и 1.2 не изменён.
- Преобразование пробелов в DOM-заголовках проверено автоматическими тестами. В последнем браузерном снимке проблемные заголовки не встречались; полностью независимой end-to-end проверки именно этих заголовков не заявлено.
- Длинная история может содержать ссылку `sandbox:` на файл из исходной сессии: переносимость самих бинарных вложений не гарантируется. Последний ответ, взятый из DOM до перезагрузки, полезно сравнить с оригиналом.
- Новые функции ChatGPT не означают повторного полноценного браузерного тестирования Claude/Grok/DeepSeek/Shared в этом выпуске.

## Установка и обновление

1. Скачайте `Chat-Context-Exporter-1.2.zip` из GitHub Release `v1.2`.
2. Проверьте SHA-256 файла по `SHA256SUMS.txt`.
3. Распакуйте в постоянную папку, где `manifest.json` находится непосредственно в корне.
4. Откройте `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное расширение».
5. Если обновляете предыдущую версию, распакуйте новый комплект вместо предыдущих файлов и нажмите «Обновить» на странице расширений.

## Предупреждения

- Для пассивного чтения штатных ответов ChatGPT, Claude и Grok расширение использует чувствительное разрешение `debugger`; Chrome может показывать соответствующее предупреждение.
- Программа не гарантирует соответствия правилам сторонних AI-сервисов, отсутствия санкций со стороны сервисов или постоянной совместимости с их интерфейсами.
- Экспорт обрабатывается локально; расширение не отправляет собственные backend/API-запросы для чтения истории ChatGPT.
- Программа бесплатна, распространяется по MIT, без гарантий и без Chrome Web Store. Планируемые TXT/HTML/PDF не реализованы и не имеют обещанных сроков.
