# Chat Context Exporter 1.0 — Release Notes

**Версия:** 1.0  
**Тип:** первый стабильный публичный выпуск  
**Распространение:** исключительно через GitHub Releases, ручная установка в Chrome/Chromium.

## Возможности

- Локальное сохранение AI-диалогов в Markdown (`.md`) из ChatGPT, Claude, Grok и DeepSeek.
- ChatGPT: обычные авторизованные чаты (включая Projects/Custom GPT), опубликованные Shared-ссылки; обработка paginated history.
- Для завершенных по лимиту ChatGPT-обсуждений: при наличии плашки лимита snapshot видимого последнего assistant response до reload и его приоритет при построении Markdown; поддерживаются file-only user turns.
- Нормализация targeted replies, прерванных preamble-сообщений, сгенерированных файловых карточек.
- Дополнительный проход для проверки полноты (выключен по умолчанию), технический лог (выключен по умолчанию).

**Функциональная база:** принятая версия 0.8.8.1. Логика экспорта в 1.0 не изменялась; изменения относятся к нумерации, пользовательской документации и материалам распространения.

## Установка

1. Скачайте ZIP-файл из раздела **Assets** этого релиза.
2. Распакуйте архив в постоянный каталог, где `manifest.json` находится в корне.
3. Откройте `chrome://extensions`, включите **Developer mode** и выберите **Load unpacked**.
4. Укажите каталог с `manifest.json`; откройте диалог в одном из поддерживаемых AI-сервисов и нажмите значок расширения.

Подробная инструкция, описание настроек и ограничений находятся в [README.md](README.md).

## Предупреждения

- Chrome может показывать предупреждение об отладке вкладки: расширение использует разрешение **`debugger`** для пассивного наблюдения штатных сетевых ответов. Это ожидаемо во время экспорта.
- Условия OpenAI содержат запрет на автоматизированное/программное извлечение данных и результатов. Выбранная архитектура минимизирует вмешательство, но не гарантирует соответствия правилам платформ или отсутствия риска для аккаунта. Перед применением ознакомьтесь с условиями каждого сервиса.
- История обрабатывается локально. Приложение не передает экспорт на сервер разработчика и не создает собственных запросов к внутренним AI backend API.
- Программа предоставляется «как есть», без гарантий дальнейших обновлений, поддержки, совместимости или сроков исправления ошибок. Авторские публикации бесплатны и доступны только через GitHub.
- Другие форматы (TXT, HTML, PDF) лишь рассматриваются; сроки и сама реализация не гарантируются.

## Проверка архива

Сверьте SHA-256 файла ZIP с опубликованным рядом с релизом `SHA256SUMS.txt`. Не используйте сторонние установщики или зеркала.
