# Chat Context Exporter 1.0.40

Расширена существующая панель процесса для основного API-сценария. Панель начинает обновляться до ответа сервера; показывает фазу, число полученных страниц и записей; при постраничной загрузке обновляет счетчики; при нормализации длинной истории обновляет число обработанных записей партиями по 100; затем показывает формирование Markdown и его сохранение.

Общий объем API-истории заранее неизвестен, поэтому показывается анимированный индикатор без выдуманного процента. После подготовки файла анимация останавливается. Настройки автосохранения сохранены: при выключенном автосохранении доступна ручная кнопка «Сохранить», после ошибки автоматической записи можно повторить сохранение.

Кнопка отмены прерывает текущий API-запрос через AbortController. DOM-сканирование сохраняет свои прежние счетчики и подписи; если включен DOM backup и API не удался, панель переключается на DOM-показатели. При ошибке API без резервного разбора панель прекращает анимацию и показывает ошибку.

В диагностическом логе теперь фиксируются события API_PROGRESS с фазой, количеством страниц, исходных сообщений и нормализованных записей.

Проверки: полный экспорт приложенного ответа сервера (99 записей, 16 сообщений) с автосохранением, ручным сохранением и ошибкой автосохранения; искусственная трехстраничная история с проверкой счетчиков и порядка; отмена активного сетевого запроса; отрисовка панели и остановка анимации на завершении; 12 прежних регрессионных проверок и 8 проверок Markdown. Проверки выполнены в тестовом окружении, реальный Chrome пользователя не запускался.

Установка: заменить файлы распакованного расширения, перезагрузить его в chrome://extensions/ и обновить вкладку чата.
