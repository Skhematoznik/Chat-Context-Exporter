# Chat Context Exporter

<p align="center">
  <img src="icons/icon128.png" width="96" height="96" alt="Chat Context Exporter">
</p>

**Chat Context Exporter** — расширение для Google Chrome, которое сохраняет открытый диалог ChatGPT в Markdown (`.md`) с проверкой полноты экспорта.

Проект создавался прежде всего для длинных рабочих чатов, где обычное копирование страницы или сохранение MHTML ненадежно из-за виртуализации интерфейса ChatGPT: в DOM одновременно может находиться только часть истории. Расширение самостоятельно проходит чат, накапливает сообщения и перед сохранением проверяет, удалось ли сшить историю целиком.

Текущая версия: **1.0.25**.

> Проект не связан с OpenAI и не является официальным расширением ChatGPT.

## Возможности

- экспорт открытого чата ChatGPT в Markdown одним нажатием;
- работа с длинными виртуализированными диалогами;
- накопление сообщений при прокрутке вместо чтения только текущего DOM;
- сохранение ролей `Пользователь` / `ChatGPT`;
- сохранение Markdown-разметки, таблиц и блоков кода;
- сохранение имен пользовательских вложений, когда они доступны в интерфейсе;
- сохранение сгенерированных ChatGPT артефактов, когда они доступны в DOM;
- сохранение промежуточных сообщений и раскрытых данных обработки, когда их можно надежно извлечь;
- восстановление служебных turn-slot, которые не являются обычными сообщениями;
- checkpoint в `chrome.storage.local`, чтобы уже собранные данные не терялись при длительном проходе;
- пауза при скрытии вкладки и продолжение после возврата;
- автоматическое сохранение результата или ручной выбор места;
- дополнительный диагностический лог;
- явное различие между подтвержденным полным и неполным экспортом.

## Главное отличие

Расширение **не считает файл полным только потому, что дошло до нижней части страницы**.

Перед статусом `COMPLETE` оно сопоставляет несколько независимых признаков:

- canonical `message-id` сообщений;
- последовательность turn-slot чата;
- prompt-группы из TOC, если ChatGPT их предоставляет;
- связность цепочки сообщений от начала до конца;
- стабильность повторных наблюдений сообщений;
- служебные `PROCESSING_ONLY`, `AUXILIARY_ASSISTANT` и `EMPTY_OR_ABORTED` turn-slot;
- отсутствие неразрешенных разрывов.

Если полнота не доказана, файл сохраняется как неполный с префиксом:

```text
НЕПОЛНЫЙ - <название чата>.md
```

Внутри такого файла также присутствует предупреждение и диагностический footer.

## Поддерживаемые сайты

Текущая версия запускается на:

- `https://chatgpt.com/`
- `https://chat.openai.com/`

Chrome получает доступ к странице только после явного нажатия пользователем на кнопку расширения.

## Установка

### Вариант 1. GitHub Release

1. Скачайте ZIP текущего релиза.
2. Распакуйте его в отдельную постоянную папку.
3. Откройте в Chrome:

```text
chrome://extensions/
```

4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку, в которой находится `manifest.json`.
7. При необходимости закрепите Chat Context Exporter на панели Chrome.

> Не удаляйте и не перемещайте распакованную папку после установки: Chrome загружает расширение непосредственно из нее.

### Вариант 2. Из репозитория

Клонируйте репозиторий и загрузите его корневую папку через `chrome://extensions/` → **Загрузить распакованное расширение**.

Сборка не требуется: расширение написано на обычных HTML/CSS/JavaScript и использует Manifest V3.

## Использование

1. Откройте нужный чат ChatGPT.
2. Нажмите значок **Chat Context Exporter**.
3. Не закрывайте вкладку до окончания экспорта. Переключаться на другие вкладки можно: экспорт поставится на паузу и продолжится после возврата.
4. Расширение самостоятельно определит направление прохода, найдет начало чата и просканирует историю до конца.
5. После проверки будет сохранен `.md` файл.

Для длинных чатов экспорт может занимать заметное время. Это штатно: приоритет проекта — **полнота результата, а не максимальная скорость прокрутки**.

## Статусы результата

### `COMPLETE`

Расширение смогло доказать полноту цепочки по доступным структурным данным ChatGPT.

### `INCOMPLETE`

Остался хотя бы один существенный разрыв, нестабильное сообщение, неизвестный turn-slot или иная причина, из-за которой полноту нельзя подтвердить.

`INCOMPLETE` не означает автоматически, что весь файл бесполезен. Это означает, что расширение **не дает ложной гарантии**, что экспорт содержит весь чат.

## Что находится в Markdown

Для обычного сообщения добавляется служебный комментарий вида:

```html
<!-- conversation-message: 42 role: assistant message-id: ... turn-id: ... -->
```

Он нужен для проверки порядка и дедупликации. Затем идет обычный читаемый Markdown.

Для подтвержденных служебных turn-slot используются отдельные markers, например:

```html
<!-- noncanonical-turn: ... role: assistant type: PROCESSING_ONLY -->
```

Внизу файла находится технический footer с версией экспортера, статусом, количеством сообщений, turn-slot, processing-блоков, артефактов и временем выполнения.

## Настройки

Страница параметров Chrome содержит два переключателя.

### Автоматически сохранять экспорт

По умолчанию включено. После успешной проверки файл автоматически отправляется в папку загрузок браузера.

Если отключить опцию, расширение показывает кнопку сохранения с выбором места.

### Сохранять диагностический лог

По умолчанию выключено.

При включении после запуска дополнительно сохраняется диагностический текстовый файл. Он содержит ход сканирования, счетчики, состояния verifier и причины repair/recovery.

Диагностический лог предназначен для поиска ошибок экспортера и **не записывает полный текст переписки**.

## Разрешения Chrome

| Разрешение | Для чего используется |
| --- | --- |
| `activeTab` | доступ к текущей вкладке только после действия пользователя |
| `scripting` | запуск экспортера на открытой странице ChatGPT |
| `storage` | настройки, checkpoint и промежуточное состояние |
| `unlimitedStorage` | длинные чаты могут требовать большой локальный checkpoint |
| `downloads` | сохранение Markdown и диагностического лога |
| `contextMenus` | быстрые переключатели настроек в меню расширения |

Расширение не запрашивает постоянный доступ ко всем сайтам.

## Приватность

В версии 1.0.25 нет кода, отправляющего содержимое чатов на внешние серверы.

Обработка выполняется локально в браузере:

- содержимое страницы читается только после запуска расширения пользователем;
- промежуточные данные и checkpoint хранятся в `chrome.storage.local`;
- итоговый Markdown сохраняется через стандартный механизм Chrome Downloads;
- диагностический лог также сохраняется локально;
- расширение не содержит `fetch`, `XMLHttpRequest`, WebSocket или другой собственной сетевой отправки данных.

Подробности: [`PRIVACY.md`](PRIVACY.md).

## Ограничения

ChatGPT является динамическим веб-приложением, поэтому DOM и внутренняя разметка могут измениться без предупреждения. После изменений интерфейса расширению может потребоваться адаптация.

Также следует учитывать:

- MHTML и содержимое текущего DOM не являются надежным эталоном полноты длинного чата;
- отдельные даты/временные разделители сохраняются только при достаточной уверенности в их привязке;
- если сам ChatGPT после перезагрузки уже перестал отдавать ранее видимый ответ, расширение не может восстановить его из сети задним числом;
- некоторые служебные элементы ChatGPT намеренно остаются `UNRESOLVED`, если их тип нельзя классифицировать безопасно;
- скорость экспорта зависит от длины чата, виртуализации ChatGPT и производительности вкладки.

## Если экспорт завершился как `INCOMPLETE`

Для диагностики полезно приложить к Issue:

1. версию расширения;
2. диагностический лог;
3. сохраненный `НЕПОЛНЫЙ - ...md`;
4. при возможности MHTML той же страницы;
5. краткое описание: была ли вкладка широкой/узкой, переключались ли вкладки, был ли чат полностью загружен до запуска.

Не публикуйте приватные чаты и логи в открытом Issue, если в них могут находиться конфиденциальные данные.

## Версия 1.0.25

`1.0.25` исправляет узкий no-TOC сценарий: локальный `TARGETED_REPAIR` теперь может безопасно исследовать небольшое число unresolved turn-slot даже тогда, когда именно эти slot пока разрывают canonical chain.

Критерий `COMPLETE` при этом не ослаблен: после repair прежний verifier заново обязан доказать полную связность и стабильность истории.

Подробности: [`docs/RELEASE_1.0.25.md`](docs/RELEASE_1.0.25.md).

## Разработка

Проект не требует npm, bundler или отдельного build-step.

Минимальная проверка JavaScript перед публикацией:

```bash
node --check background.js
node --check exporter.js
node --check options.js
```

Проверка `manifest.json`:

```bash
python -m json.tool manifest.json
```
