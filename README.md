# Chat Context Exporter

**Chat Context Exporter** — неофициальное бесплатное расширение Chrome (Manifest V3) для локального сохранения истории AI-диалогов в Markdown (`.md`). Поддерживаются ChatGPT (обычные чаты и Shared), Claude, Grok и DeepSeek в пределах описанных ниже ограничений.

**Версия:** `1.0` — стабильная базовая версия. Официальные архивы автора размещаются на GitHub в разделе Releases. Исходный код и сборки автора публикуются **исключительно на GitHub**. Расширение **не размещается в Chrome Web Store** и устанавливается вручную через режим разработчика. Проект не связан с OpenAI, Google, Anthropic, xAI или DeepSeek.

> **Внимание: разрешение `debugger`, ограничения правил сервисов и риск для аккаунта.** Перед установкой прочитайте разделы [«Почему Chrome предупреждает об отладке»](#почему-chrome-предупреждает-об-отладке) и [«Правила сервисов и риски»](#правила-сервисов-и-риски). Эта программа не гарантирует допустимость ее использования по условиям какого-либо AI-сервиса.

## Скачать и установить в Google Chrome

1. Откройте официальный репозиторий: **https://github.com/Skhematoznik/Chat-Context-Exporter**. Перейдите во вкладку **Releases**: https://github.com/Skhematoznik/Chat-Context-Exporter/releases.
2. Выберите нужный выпуск и скачайте **ZIP-файл расширения** из секции **Assets**. Не используйте неизвестные зеркала, переупакованные архивы и сторонние «установщики». Если для выпуска опубликована SHA-256, сверьте контрольную сумму скачанного ZIP.
3. Распакуйте ZIP в отдельную постоянную папку, например `C:\Extensions\Chat-Context-Exporter`. В этой папке непосредственно должен находиться файл `manifest.json` вместе с каталогами `src` и `assets`. **Не выбирайте сам ZIP** и не выбирайте родительскую папку, если `manifest.json` находится уровнем ниже.
4. Откройте Chrome и в адресной строке введите **`chrome://extensions`**.
5. Включите переключатель **«Режим разработчика»** (*Developer mode*), обычно в правом верхнем углу.
6. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку из шага 3, содержащую `manifest.json`.
7. Проверьте, что в списке появилось **Chat Context Exporter**. При желании закрепите его значок через меню расширений (значок пазла) в панели Chrome.

Расширение **не обновляется автоматически через GitHub Releases**. Чтобы обновить его, скачайте новый ZIP из Releases, распакуйте в ту же папку вместо прежних файлов (или в новую папку), затем нажмите **«Обновить»/Reload** на карточке расширения в `chrome://extensions`. Не удаляйте папку, из которой загружено расширение. После ручного обновления проверьте номер версии.

Если Chrome показывает предупреждение о расширениях, установленных в режиме разработчика, это следствие выбранного способа установки. Устанавливайте только исходники, которым доверяете. Установка через Developer mode не превращает расширение в официально проверенное Chrome Web Store приложение.

## Как сохранить разговор

1. Откройте нужный разговор в поддерживаемом AI-сервисе. Для ChatGPT поддерживаются как обычные авторизованные чаты, включая маршруты проектов, так и опубликованные Shared conversations.
2. При необходимости настройте параметры расширения: **`chrome://extensions` → Chat Context Exporter → «Сведения» → «Параметры расширения»**. В разных версиях Chrome путь до кнопки настроек может отображаться иначе.
3. Нажмите значок **Chat Context Exporter** на активной вкладке с разговором. Запуск выполняется только по вашему действию.
4. Не закрывайте вкладку, не переключайте ее на другой разговор и не обновляйте страницу вручную до завершения экспорта. Расширение может само перезагрузить страницу и прокрутить историю — это предусмотрено алгоритмом сбора.
5. После завершения итоговый `.md` будет сохранен в папке загрузок, настроенной в Chrome (если включено автосохранение). Если автосохранение выключено, используйте кнопки **«Сохранить»** или **«Отмена»** на панели расширения.

**Если ChatGPT показывает «Вы достигли максимальной длины этого обсуждения»**, особенно важно запускать расширение **до ручной перезагрузки**. Оно сначала сохраняет текущий видимый последний ответ ассистента из DOM, а только затем перезагружает вкладку и собирает историю. Если страница уже перезагружена и ответ изменился, прежнюю версию расширение восстановить не может; будет сохранен тот ответ, который виден непосредственно перед запуском.

Экспорт содержит текст диалога и доступные метаданные вложений. Он **не скачивает автоматически исходные файлы всех вложений** и не гарантирует восстановления файловых ссылок, которые требуют исходной сессии сайта. Перед удалением чата проверьте итоговый `.md` вручную.

## Планируемые форматы экспорта

Сейчас расширение сохраняет диалоги только в **Markdown (`.md`)**. В дальнейшем планируется добавить возможность сохранения в **TXT (`.txt`)**, **HTML (`.html`)** и **PDF (`.pdf`)**.

**Сроки реализации не определены.** Автор не гарантирует, что эти форматы будут добавлены, и не принимает обязательств по их разработке или выпуску в определенные сроки.

## Почему Chrome предупреждает об отладке

Для ChatGPT, Claude и Grok (а также ChatGPT Shared) расширение использует штатный браузерный механизм **`chrome.debugger`**, подключаясь к **текущей вкладке** после нажатия пользователем на значок расширения. Это позволяет пассивно читать сетевые ответы, уже получаемые самой страницей в процессе обычной загрузки истории.

В этот момент Chrome может показать заметную плашку наподобие **«Chat Context Exporter выполняет отладку этой вкладки»** или **«[расширение] started debugging this browser»**. **Это ожидаемое поведение во время экспорта, а не свидетельство взлома браузера.** По завершении, отмене или ошибке расширение должно отключить debugger. Если предупреждение остается после окончания работы, завершите экспорт, проверьте состояние расширения и при повторении проблемы создайте GitHub Issue.

Разрешение `debugger` технически чувствительное и обладает широкими возможностями. В данной реализации оно используется для `Network.enable`, наблюдения штатных запросов и `Network.getResponseBody` по выбранному разговору, а не для модификации запросов. Проверить поведение можно по опубликованному исходному коду и технической документации.

## Архитектура: минимум воздействий, но не «нулевое» взаимодействие

Расширение специально спроектировано для минимизации вмешательства в AI-приложения независимо от используемого сервиса:

- Не отправляет **собственные** `fetch`/`XMLHttpRequest`/`WebSocket` запросы к внутренним AI backend API и не переиспользует cookie, токены сессии или заголовки авторизации для самостоятельных запросов.
- Не изменяет сетевые запросы и ответы сайта, не использует перехват с заменой payload и не подменяет сетевые функции страницы.
- Не выполняет код расширения в JavaScript-контексте сайта (`MAIN` world), не использует CDP `Runtime.evaluate` и не обращается к внутренним React/другим application-state функциям сайта.
- Content script запускается в изолированном контексте Chrome (`ISOLATED`); чтение DOM выполняется без изменения содержимого сообщений. Для DeepSeek используется read-only чтение уже имеющейся локальной записи IndexedDB.
- Допускает **обычную перезагрузку текущей вкладки и управление прокруткой** для получения штатных страниц истории, а также отображает собственную панель расширения. Это реальные действия в интерфейсе браузера, поэтому было бы неверно утверждать, что расширение «совсем не взаимодействует со страницей».
- Обрабатывает разговор локально, сохраняет Markdown через возможности Chrome и **не передает историю на сервер автора расширения**.

Подробные технические инварианты и особенности адаптеров: [Архитектура](docs/ARCHITECTURE.md), [Adapter Guide](ADAPTER_GUIDE.md), [Безопасность](SECURITY.md), [Конфиденциальность](PRIVACY.md).

**Эта архитектура предназначена для снижения вмешательства и рисков; она НЕ гарантирует соблюдение правил сторонних сервисов, отсутствие детектирования автоматизации или защиту аккаунта от санкций.**

## Настройки и значения по умолчанию

Откройте настройки расширения в Chrome. Изменения сохраняются автоматически в локальном хранилище расширения.

| Настройка | По умолчанию | Для чего нужна |
| --- | --- | --- |
| **Автосохранение** | **Включено** | Сохранять итоговый `.md` в каталог загрузок после успешного экспорта. Если выключить, появляется выбор «Сохранить»/«Отмена». |
| **Закрывать панель после сохранения** | **Включено** | Убирать панель после сохранения готового файла. |
| **Сохранять лог** | **Выключено** | Дополнительный технический `.txt` с ходом экспорта; обычно нужен разработчику при диагностике. |
| **Дополнительные проходы** | **Выключены** | Повторно читать историю для сверки и дополнения пропущенных/обновленных сообщений. Увеличивают время и количество штатных reload/scroll. Для повседневного экспорта достаточно оставить выключенными; при приоритете полноты можно включить. Полноту на 100% это не гарантирует. |
| **Количество дополнительных проходов** | **1** | От 1 до 3 дополнительных проходов сверх основного, если опция включена. |
| **Минимальная задержка** | **100 мс** | Нижняя граница случайной задержки между действиями, когда алгоритм адаптера использует задержку. |
| **Максимальная задержка** | **1000 мс** | Верхняя граница той же задержки. |

Кнопка **«По умолчанию»** сбрасывает параметры на заводские. Для диагностики проблемы включите «Сохранять лог» *перед* повторным экспортом. Лог не должен включать полный текст разговора и credential headers, но может содержать адрес страницы, название чата, идентификаторы сообщений и другую техническую метаинформацию. Просмотрите файл перед публичной отправкой в GitHub Issue.

## Правила сервисов и риски

**Особое предупреждение о ChatGPT.** В [OpenAI Terms of Use](https://openai.com/policies/terms-of-use/) (для ЕЭЗ, Швейцарии и Великобритании действуют [отдельные условия](https://openai.com/policies/eu-terms-of-use/)) прямо запрещено *автоматическое или программное извлечение данных или Output*. Использование инструментов экспорта может подпадать под это ограничение. Отдельные правила могут применяться к другим AI-сервисам; пользователь должен самостоятельно ознакомиться с их действующей редакцией и оценить допустимость своего применения. Размещение расширения на GitHub, его бесплатность, локальная обработка, отсутствие собственных backend-запросов и passive/read-only проектирование **не означают разрешения OpenAI либо иных поставщиков**.

**О рисках безопасности и блокировки аккаунтов.** Публично документировались вредоносные расширения, выдававшие себя за помощников ChatGPT и похищавшие session tokens для передачи сторонним операторам (см. [Malwarebytes, январь 2026](https://www.malwarebytes.com/blog/news/2026/01/malicious-chrome-extensions-can-spy-on-your-chatgpt-chats)). OpenAI указывает, что нарушения условий и подозрительная либо неавторизованная активность могут привести к предупреждениям, ограничениям, временному приостановлению или деактивации аккаунта (см. [официальную справку](https://help.openai.com/en/articles/10562188-why-was-my-openai-account-deactivated)). Эти факты **не доказывают**, что конкретные пользователи были заблокированы именно из-за указанных вредоносных расширений; такая причинная связь в приведенных источниках не установлена.

Именно с учетом этих рисков Chat Context Exporter **не извлекает cookies/access tokens для самостоятельных запросов** и не отправляет их на сервер автора. Однако это не устраняет ни юридические, ни технические риски использования сторонней автоматизации. Для авторизованных/private ChatGPT страниц проект рекомендует **не использовать расширение без самостоятельного подтверждения допустимости такого использования**. Все действия пользователь выполняет на свой риск.

## Конфиденциальность и безопасность

Обработка осуществляется локально в браузере. В рамках сбора расширение может читать сообщения, временные метки, технические идентификаторы, метаданные вложений, сетевые response bodies штатных запросов, а для DeepSeek — историю из локальной IndexedDB. При лимите ChatGPT последний видимый ответ временно сохраняется в `chrome.storage.session`, чтобы не потерять его при reload. [Политика конфиденциальности](PRIVACY.md) и [Модель безопасности](SECURITY.md) содержат подробности.

Скачанный Markdown может содержать личные данные и конфиденциальные сведения из переписки. Храните его и делитесь им с той же осторожностью, что и исходным чатом. Не устанавливайте переупакованные версии из неизвестных источников.

## Ошибки, обновления и поддержка

Проект распространяется **бесплатно и «как есть»**; сопровождающий **не гарантирует** совместимость с будущими версиями ChatGPT, Claude, Grok или DeepSeek, исправление ошибок, постоянную поддержку и выпуск обновлений. Изменения и исправления могут появляться по усмотрению сопровождающего; публикация GitHub Issue не создает обязанности исправить проблему или соблюдать срок. Предложения и сообщения об ошибках: https://github.com/Skhematoznik/Chat-Context-Exporter/issues.

При сообщении об ошибке желательно указать версию расширения, браузер, сервис и точное сообщение из панели. При необходимости приложите технический лог, **предварительно удалив из него чувствительную информацию**. Не отправляйте чужие переписки, токены и cookies.
