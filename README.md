# Chat Context Exporter 1.0.39

Исправлен выбор названия: полный document.title страницы имеет приоритет перед сокращенным title из API. Это сохраняет имя проекта и в имени файла, и в заголовке Markdown. Если title страницы пустой, используется название из API.

Пример: MT5 FRAMEWORK - № 7 Фреймворк.md; заголовок: # MT5 FRAMEWORK - № 7 Фреймворк.

Недопустимые символы файловой системы по-прежнему заменяются только в имени файла. Форматирование, ссылки и даты версии 1.0.38 сохранены.

Проверено на полном тестовом пути экспорта: название с проектом и резервное название при пустом document.title; для каждого варианта автоматическое сохранение, ручное сохранение и повтор после ошибки скачивания. Живой браузер пользователя не проверялся.

Обновление: заменить файлы, перезагрузить расширение в chrome://extensions/ и обновить вкладку чата.
