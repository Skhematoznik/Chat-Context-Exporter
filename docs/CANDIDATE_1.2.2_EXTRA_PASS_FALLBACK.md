- `23:40:13` — старт, версия в журнале неверно указана как 1.2 при manifest 1.2.1.

- Журнал содержал повторные `CANCEL_REQUESTED`/`DEBUGGER_DETACHED` после исходной ошибки.

## Изменения

1. `service-worker.js`: `completedPasses` считается только при `completeCapturePass` — при достижении начала истории. Если ошибка возникает в необязательном проходе после подтверждённого полного основного, неполная попытка исключается, сессия переводится в `ready` с полями `captureWarning`, `skippedExtraPasses` и событием `CHATGPT_EXTRA_PASS_SKIPPED`. Без завершённого основного прохода — жёсткая ошибка; данные не сохраняются.
2. `start.js`: после reload при Stop в дополнительном проходе выполняется `skip-extra-pass`, **без очередной перезагрузки**. При тайм-ауте Stop на дополнительном проходе используется тот же безопасный fallback. Основной проход по-прежнему ждёт Stop до старта; если начальная страница могла быть получена до окончания генерации, разрешён только ограниченный повтор.
3. Экспорт `.md`: при fallback над заголовком диалога добавляется предупреждение на русском языке; `EXPORT_WITH_WARNING`, `EXPORT_READY`, `COMPLETED` отражают фактическое число завершённых и запрошенных проходов, а не выдают 2 из 2 за успех.
4. Runtime `namespace.js` и Manifest синхронизированы как `1.2.2`; очистка после ошибки не формирует повторное событие отмены/отключения.
5. Пассивная архитектура сохранена: наблюдение за штатными ответами браузера, без собственных запросов к API, без кнопочных действий Stop/Retry.

## Браузерная приемка

1. Из отдельного каталога загрузить установочный пакет 1.2.2; остальные копии расширения отключить.
2. Оставить **включённый дополнительный проход** и `Сохранять лог`. Экспортировать длинный чат `№ 7 AWF`. Если второй проход вновь увидит Stop — проверить, что появляется `CHATGPT_EXTRA_PASS_SKIPPED`, **Markdown сохраняется с предупреждением**, а первый pass содержит все страницы до `has_previous_page=false`.
3. Проверить обычный случай, когда оба прохода завершились: итог без предупреждения, лог `passes=2`, `requestedPasses=2`.
4. Проверить короткий чат / свежую генерацию: до исчезновения Stop прокрутка не начинается; остановка оператором во время ожидания не приводит к зависшей debugger-сессии.
5. При разрыве курсорной цепочки первого прохода никакой неполный Markdown не должен создаваться.

**Решение:** кандидат 1.2.2 не является базлайном до браузерной приёмки. В публичный GitHub ничего не загружалось.
