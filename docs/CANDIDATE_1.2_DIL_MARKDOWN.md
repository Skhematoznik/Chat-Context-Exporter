# Кандидат 1.2 — нормализация DIL/MDX в Markdown

**Статус:** CANDIDATE / BROWSER ACCEPTANCE PENDING. Основа — текущий кандидат 1.1 с исправлением HTTP 403, исходный stable baseline 1.0 не менялся.

## Причина

Экспорт `№ 7 AWF.md` от 12.10.2026 завершился успешно: 3 страницы, 26 сообщений, достигнуто начало и конец истории. Но ответы ассистента содержали DIL-компоненты `<Link>`, `<row>`, `<box>`, `<badge>` и `{#each}`, которые раньше копировались в `.md` как сырой текст, хотя часть содержимого уже была нормальным Markdown.

## Реализация

- Новый изолированный background-модуль `src/adapters/chatgpt/dil-to-markdown.js`; используется только в ChatGPT authenticated-thread и ChatGPT Shared, только для сообщений ассистента.
- Порядок: получение text.parts → `content_references` → targeted-reply normalization → DIL→Markdown → generated file cards → сборка Markdown. Позиционные индексы ссылок не нарушаются.
- `<Link>` → обычный Markdown link, в том числе внутри существующей Markdown-таблицы. `<badge>` → текст статуса, layout-контейнеры → читаемый текст, декоративные иконки и кнопки копирования опускаются.
- Данные статического `{#each}` с literal-array из `name`, `value`, `desc` восстанавливаются в Markdown-таблицу, без выполнения JS.
- Настоящие fenced code / inline code не изменяются. Неизвестные динамические конструкции сохраняются как исходный DIL-код внутри Markdown code fence. Некорректная вложенность компонентов возвращается без разрушительного преобразования.
- На ChatGPT Shared преобразование подключено в тот же этап после source citation normalization; обычные DOM-адаптеры Grok, Claude, DeepSeek не затронуты.
- Сохраняются все правила HTTP 403 retry/reload кандидата 1.1.

## Локальные проверки

`node --test tests/chatgpt-dil-to-markdown.test.js tests/chatgpt-http-recovery.test.js` — 18/18 PASS (11 новых и 7 предыдущих). В том числе проверены настоящий JSON ChatGPT, экспортированный текст `№ 7 AWF.md`, ссылки в таблицах, вложенные структуры, образцы кода и динамические показатели; реальные пользовательские данные **не включены** в дистрибутив и в тестовый каталог.

Ограничение: это не универсальный DIL-рендерер. Неизвестные визуализации, интерактивные элементы и произвольные условия JavaScript не воспроизводятся с полной точностью. Динамические блоки не исполняются. Тестирование установкой в Chrome и ChatGPT Shared ожидается.
