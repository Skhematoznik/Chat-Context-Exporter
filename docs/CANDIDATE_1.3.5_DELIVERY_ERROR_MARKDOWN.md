## Изменения

1. Детектор видимой ошибки доставки в `src/adapters/chatgpt/generation-guard.js`; игнорируются скрытые уведомления, сообщения истории и нераспознанные тексты.
2. На **необязательном** проходе после подтверждённого полного первого ошибка доставки означает безопасный `skip` без повторной перезагрузки. В журнале `CHATGPT_EXTRA_PASS_DELIVERY_FAILURE`; в предупреждении указана именно ошибка доставки. Полный первый проход остаётся сохранённым.
3. DIL-конвертер удаляет непереносимые tool-цитаты; `WritingBlock` сохраняет исходный текст и вложенный код без попыток исполнять содержимое.
4. Markdown-экспортер ставит `text` для безъязыковых fenced code blocks (MD040); языки из источника не подменяются. Плейсхолдеры вида `<GUID>` экранируются вне кода (MD033).
