# Chat Context Exporter 1.0.26

Версия `1.0.26` — визуальное обновление стабильной функциональной базы `1.0.25`.

## Что изменено

- заменен комплект иконок расширения `16/32/48/128 px`;
- `manifest.json` обновлен до версии `1.0.26`;
- функциональная логика экспортера не изменялась.

Scanner, verifier, checkpoint, targeted repair, serializer и критерии `COMPLETE / INCOMPLETE` сохранены без изменений относительно проверенной версии `1.0.25`.

## Установка

1. Скачайте `Chat-Context-Exporter-v1.0.26.zip`.
2. Распакуйте архив в отдельную папку.
3. Откройте `chrome://extensions/`.
4. Включите режим разработчика.
5. Нажмите «Загрузить распакованное расширение».
6. Выберите папку, содержащую `manifest.json`.
