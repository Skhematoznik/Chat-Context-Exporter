# Privacy

Chat Context Exporter выполняет обработку локально в браузере пользователя и не отправляет собранные разговоры на сторонний сервер расширения.

## Какие данные читаются

В зависимости от адаптера расширение может читать:

- текст сообщений пользователя и ассистента;
- идентификаторы сообщений и parent-связи;
- метаданные, необходимые для определения полноты/порядка;
- сведения о наличии вложений;
- DOM текущей страницы для еще не мигрированных DOM-адаптеров.

Для Grok 0.5.0 данные берутся из response body, который сама страница Grok получает при своей штатной загрузке.

## Сетевой режим

Grok использует `chrome.debugger` и CDP `Network` только как пассивный транспорт наблюдения.

Расширение:

- не создает собственные backend API-запросы к Grok;
- не подменяет и не модифицирует запросы/ответы;
- не извлекает auth/session tokens для повторного использования;
- не патчит `fetch`, `XMLHttpRequest` или `WebSocket` страницы;
- автоматически перезагружает текущую вкладку после явного запуска пользователем, чтобы увидеть штатный ответ страницы.

Debugger отключается после завершения захвата или ошибки/отмены.

## Логи

Runtime ведет техническую диагностику. Если включено `Сохранять лог`, создается локальный TXT-файл.

В лог могут попасть URL/ID текущего диалога, размеры ответов, requestId, счетчики сообщений и диагностические ID. Полное response body и полный текст разговора в технический лог не записываются.

## Сохранение

Markdown и TXT-лог сохраняются через браузерный Downloads API. При автосохранении используется каталог загрузок, настроенный в браузере. Расширение не задает скрытый абсолютный путь.
