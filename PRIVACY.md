# Политика конфиденциальности Chat Context Exporter

Дата редакции: 27 сентября 2026 года.

## 1. Общий принцип

Chat Context Exporter предназначен для локального экспорта истории AI-диалогов из DOM страницы, доступной пользователю в браузере.

Расширение не имеет собственного сервера телеметрии, аналитики или синхронизации и не передает содержимое экспортируемых диалогов разработчику проекта или сторонним сервисам.

## 2. Какие данные обрабатываются

Во время работы расширение может локально обрабатывать:

- текст сообщений пользователя и ассистента, присутствующий в DOM;
- структуру форматирования сообщений;
- DOM-идентификаторы, необходимые для дедупликации;
- title текущей страницы;
- URL текущей страницы для технической диагностики;
- размеры и положение scroll-контейнера;
- счетчики сообщений, проходов и шагов прокрутки;
- настройки расширения.

Эти данные обрабатываются для выполнения экспорта и диагностики работы расширения.

## 3. Передача данных

Chat Context Exporter не отправляет содержимое диалогов на сервер разработчика и не содержит кода для самостоятельного обращения к API AI-сервиса за историей чата.

Расширение не использует `fetch`, `XMLHttpRequest` или `WebSocket` для получения истории диалога и не извлекает токены для таких запросов.

Сетевые запросы, которые сам сайт выполняет вследствие обычной прокрутки интерфейса, принадлежат веб-приложению сайта и не формируются Chat Context Exporter.

## 4. Локальное хранение настроек

Настройки сохраняются через `chrome.storage.local` в профиле браузера пользователя.

К ним относятся, в частности:

- режим автосохранения;
- сохранение технического лога;
- автоматическое закрытие панели;
- дополнительные проходы;
- диапазон задержек прокрутки.

Проект не синхронизирует эти настройки со своим сервером.

## 5. Экспортируемые файлы

Итоговый файл диалога создается локально и сохраняется через стандартный механизм `chrome.downloads`.

При автосохранении используется каталог загрузок, настроенный в браузере пользователя. При ручном сохранении браузер показывает стандартный диалог выбора места.

После сохранения содержимое файла находится под контролем пользователя и далее обрабатывается операционной системой, браузером, облачным клиентом или другими программами в соответствии с настройками самого пользователя.

## 6. Технический лог

Сохранение технического лога по умолчанию выключено.

Если пользователь включает эту настройку, локально создается TXT-файл, который может содержать:

- URL страницы без query и hash;
- title страницы;
- версию расширения;
- выбранный адаптер;
- значения настроек;
- технические параметры прокрутки;
- счетчики сообщений и проходов;
- длительность операций;
- диагностические ошибки.

Текст экспортируемого диалога в технический лог намеренно не записывается.

Пользователь должен учитывать, что URL и title страницы сами по себе могут содержать информацию, которую он считает чувствительной.

## 7. Учетные данные

Расширение не предназначено для чтения, сохранения или передачи паролей, access token, session token или иных секретов авторизации AI-сервиса.

Если такие данные случайно присутствуют внутри текста самого диалога, они рассматриваются как часть пользовательского контента и могут попасть в экспортируемый файл, потому что расширение сохраняет видимый текст беседы.

## 8. Сторонние сервисы

Chat Context Exporter работает внутри страниц сторонних AI-сервисов. Политики конфиденциальности, условия использования и сетевое поведение этих сайтов не контролируются данным проектом.

Пользователь самостоятельно отвечает за выбор сервиса и соблюдение его правил.

## 9. Изменения политики

При изменении модели обработки данных эта политика должна быть обновлена вместе с соответствующей версией расширения.

Изменения, которые добавляют передачу пользовательского контента на внешний сервер, аналитику или самостоятельные сетевые запросы за историей чата, считаются архитектурно значимыми и не должны вноситься без явного пересмотра принципов проекта и настоящей политики.
