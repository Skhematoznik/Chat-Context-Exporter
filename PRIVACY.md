# Политика приватности Chat Context Exporter

Актуально для версии **1.0.25**.

Chat Context Exporter предназначен для локального экспорта открытого пользователем чата ChatGPT в Markdown.

## Какие данные обрабатываются

Во время запуска расширение может читать данные текущей страницы ChatGPT, необходимые для экспорта:

- текст сообщений;
- роли сообщений;
- идентификаторы сообщений и turn;
- пользовательски видимые вложения и артефакты;
- доступные processing-блоки;
- служебную структуру диалога, используемую для проверки полноты.

## Где выполняется обработка

Обработка выполняется локально в браузере пользователя.

Версия 1.0.25 не содержит собственной отправки содержимого чата на внешние серверы и не использует `fetch`, `XMLHttpRequest`, WebSocket или аналогичный сетевой транспорт.

## Локальное хранение

`chrome.storage.local` используется для:

- настроек расширения;
- checkpoint длительного экспорта;
- промежуточного состояния, необходимого для продолжения и проверки полноты.

## Сохранение файлов

Markdown и, при включенной опции, диагностический лог сохраняются через Chrome Downloads на устройство пользователя.

Диагностический лог предназначен для технического анализа работы экспортера. Он содержит счетчики, идентификаторы, этапы сканирования, verifier/repair-состояния и другие диагностические сведения, но не предназначен для сохранения полного текста переписки.

## Передача третьим лицам

Само расширение версии 1.0.25 не реализует передачу экспортированных чатов третьим лицам.

Пользователь самостоятельно распоряжается созданными `.md` и диагностическими файлами после их сохранения.

## Изменения

Если в будущих версиях появится функциональность, изменяющая обработку или передачу данных, этот документ должен быть обновлен вместе с соответствующим релизом.
